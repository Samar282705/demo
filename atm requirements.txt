ATM Project Requirements

Create a simple ATM using HTML, CSS, and JavaScript DOM.
Create a Login section with PIN input.
Use a fixed PIN: 1234.
Show the ATM menu only after successful login.
Display initial balance: Rs. 10,000.
Add an input to enter an amount.
Add a Deposit button.
Add a Withdraw button.
Update the balance after each transaction.
Show "Insufficient Balance" if the withdrawal amount is too high.
Show a message for successful or failed actions.
